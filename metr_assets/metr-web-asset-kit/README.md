# Metr Web Graphics Asset Kit

A reusable SVG system based on measurement, instrumentation and commerce intelligence.

## Included
15 SVG assets:
measurement scale, five-tick signal, crosshair, corner brackets, analysis frame,
dimension line, technical grid, coordinate axis, section divider, metric card,
data bars, flow arrow, scan frame, registration marks and dot matrix.

Also included:
- `css/metr-graphics.css` with core design tokens and utilities
- `docs/design-tokens.json`

## Direction
Use these as a system, not decoration everywhere. Keep pages mostly dark and quiet.
Large measurement graphics can sit partially outside the viewport. Use the signal
color only for active measurements, AI states and important data.

All SVGs are editable vectors and can be used inline in React/Next.js.
